1. 什么是“类（Class）”和“对象（Object）”？
类（Class）：就像是一张“图纸”或“模具”。题目要求的 Task 类，就是定义了“任务”长什么样（有编号、类型、优先级），以及能做什么（能打印信息、能获取优先级）。
对象（Object）：就是根据图纸造出来的“实物”。比如你根据 Task 这张图纸，造出了一个具体的任务“任务1”，这个“任务1”就是一个对象。
2. 什么是“构造函数”和“析构函数”？
这两个函数管的是对象的“生”与“死”：
构造函数（Constructor）：负责“生”。当你创建一个对象时，它会自动运行。就像工厂流水线，零件一上来，构造函数就负责把编号、类型、优先级这些初始数据塞进去。
析构函数（Destructor）：负责“死”。当对象不再被需要、即将被系统回收销毁时，它会自动运行。就像垃圾回收员，在对象消失前做最后的清理或告别（比如题目要求的打印“已销毁”）。
3. 什么是“初始化列表”？
题目要求你用的这个语法，其实是一种“出厂设置”。
普通赋值：就像人出生后再去上户口、改名字，多了一步。
初始化列表：就像在出生的瞬间，直接带着身份证信息来到这个世界。在C++中，这种方式效率更高，也是更规范的写法。
